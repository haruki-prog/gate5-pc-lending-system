# Gate5 PC貸出・返却システム

Gate5で洗い出した25件の例外を、貸出・返却・結果照会まで含むWebシステムとして実装した研修成果物です。Python標準ライブラリとSQLiteだけで動作します。

## 起動方法

```powershell
cd H:\マイドライブ\研修\gate5
python app.py
```

ブラウザで `http://127.0.0.1:8055` を開きます。初回起動時に研修用の合成データを `gate5.db` に作成します。配布PDFの原本は変更していません。

利用者を切り替える場合は別ポート・別DBで起動します。

```powershell
python app.py --port 8056 --db user2.db --user-id 2
```

研修用ユーザーは、1: 佐藤花子（在籍）、2: 鈴木一郎（在籍）、3: 田中美咲（在籍・延滞あり）、4: 高橋次郎（退職・貸出中）、5: 伊藤葵（休職・貸出中）、6: 山本蓮（在籍）です。利用者IDは起動時に固定し、画面やリクエストから変更できません。

## 実装内容

- 貸出可能なノートPCの一覧、貸出申請、確認、確定、完了表示
- 自分の貸出一覧、延滞表示、返却、二重返却時の安全な結果表示
- 1人1台、在籍者だけ新規貸出、翌日から90日以内、利用目的100文字以内
- 同時実行時の再確認、端末ごとの未返却記録一意制約、1トランザクションでの貸出・返却
- 操作キーによる連打・再送防止と、応答消失後の結果照会
- 確認後の値すり替え、他人の貸出操作、CSRF、GETによる更新の拒否
- データ矛盾や調査保留中の端末を候補から除外し、通常操作を停止
- 入力エラー時の項目別表示と入力保持、完了履歴、390px幅の画面対応

データを壊し得る高優先度項目を、DB制約、`BEGIN IMMEDIATE`、確定直前の再検証、ロールバック、永続的な処理結果の順で防いでいます。

## 実装上の振り返り

一覧から単にエラーを返すだけでは、同時確定や応答消失でデータを守れませんでした。そこで、入力検証、業務ルール、DB制約、トランザクション、操作キーを別の層として組み合わせました。特に「確定したか分からない」場合に再申請を促さず、同じ操作キーの結果を照会する設計が重複防止に有効でした。

本システムは研修用の単一プロセス構成です。本番利用では、社内認証との接続、権限管理、監視、バックアップを運用環境に合わせて追加します。
